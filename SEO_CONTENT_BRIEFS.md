# Rodiwala SEO content briefs

This file turns the SEO content queue into publishable briefs. Create a page only after the facts in its brief are confirmed. Every page must be useful to a contractor, builder, site engineer or homeowner even if the reader has never heard of Rodiwala.

## Publishing rules

- Use a real author or reviewer name once approved.
- Show `Published` and `Last reviewed` dates.
- Lead with a direct answer, then explain the practical detail.
- Use tables or checklists when they make a decision easier.
- Link to the relevant material page and `/buy-construction-material`.
- Use FAQ schema only for questions and answers visible on the page.
- Do not invent prices, grades, availability, delivery times, project outcomes, reviews or technical suitability.
- Do not create a page only by swapping a city name.

## Content QA checklist

Before publishing any brief:

- [ ] The page answers the target query in the first section.
- [ ] Every technical statement has a source, reviewer or clearly labelled general-guidance boundary.
- [ ] No unsupported business claim appears.
- [ ] Title, H1, description and canonical match the page intent.
- [ ] Links to the relevant material page and buying page work.
- [ ] FAQ answers are visible if FAQ schema is present.
- [ ] The page is in the sitemap only after it returns `200`.
- [ ] The page is linked from at least one relevant existing page.
- [ ] `bun run build` passes after implementation.
- [ ] Search Console indexing is requested only after production validation.
